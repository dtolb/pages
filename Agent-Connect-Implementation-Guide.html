Memory Store ID comes from the Conversation Orchestrator quickstart. Set the firstName trait on a profile to enable name-based greetings.
06Add SMS · Swap providers

Two more channels. Any model. Same agent.

SMS is five lines different from Voice. Provider chips below show what changes in initialisation code.

Adding SMS — what changes
# Voice: TwiML endpoint
@app.route("/twiml", methods=["POST"])
def twiml():
    return agent.handle_voice(request)

# SMS: Webhook endpoint — that's it
@app.route("/webhook", methods=["POST"])
def webhook():
    return agent.handle_sms(request)
// Voice: TwiML endpoint
app.post('/twiml', (req, res) => {
  return agent.handleVoice(req, res);
});

// SMS: Webhook endpoint — that's it
app.post('/webhook', (req, res) => {
  return agent.handleSms(req, res);
});
Configure both webhook URLs in your Twilio Console. Same agent instance, same Memory store, same LLM — just a second route.
