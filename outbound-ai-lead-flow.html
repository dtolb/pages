What happens end to end

A HubSpot trigger becomes a validated, warm-transferred conversation: the AI agent handles the outreach and qualifying, and a human agent in Flex picks up the ones worth closing — already briefed.

Context handoff — preserving the data through steps 06–08

The point of the flow: the HubSpot lead data and what happened on the call both have to reach the human. One correlation ID ties them together; the live call stays in a single conference so the conversation survives the swap.

◆ Correlation ID The conversation ID / Call SID that joins the call, the TaskRouter Task, and the conference — the room is named for the Task SID, so voice and data share one key.

The customer sits in one conference the entire time, so the swap is just add the human leg, drop the AI leg — if the AI leg fails, the room and the conversation survive. This is why a conference beats a SIP REFER for real calls, and it unlocks recording and per-participant hold / coach / barge for free.

Reference for the two build platforms in this flow.

ElevenLabs

  • Agents — Quickstart Build and configure the AI voice agent (steps 04–05).
  • Twilio native integration Connect the agent to Twilio and place outbound calls (step 04).
  • Agent tools Gather and pass the structured handoff details (step 07).
  • Transfer to number — system tool Hand the live call off to a human (step 08).
  • Agent transfer — system tool Route between agents when a specialist is needed.
  • Dynamic variables Inject the HubSpot lead data into the call at start.
  • Webhook tools Push the call outcome to your backend live, mid-call.
  • Post-call webhooks Transcript + analysis after the call — for the HubSpot write-back.

Twilio

  • Make outbound phone calls Create the call via Programmable Voice (step 03).
  • Programmable Voice API Calls REST API — create and control calls.
  • Media Streams Real-time call audio to and from the AI agent (step 04).
  • Conference calls Bridge parties to move the live call (step 08).
  • Flex — warm transfer Hand off to a human agent in Flex (step 08).
  • TaskRouter — warm transfer flow Route the handoff task to the right agent.
