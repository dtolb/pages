Climb profile — select a waypoint

LAYER 00

Bones

What it adds

The extracted flight-booking system: REST API, booking UI, admin panel, auth, seed data — plus a new build: WebRTC voice in the admin panel. Place and receive calls to any user. The admin becomes a mini human agent, no tools yet.

In the Console

Account setup, a toll-free number, TwiML app + voice webhooks, API keys, .env.

Orchestrator

What it adds

Conversations Orchestrator with the AI agent deliberately stubbed — multi-threaded SMS lands in an admin chat interface alongside voice. You learn who Orchestrator is for and why, before any AI exists.

In the Console

Toll-free / 10DLC approval (a hard pre-req), Orchestrator configuration, capture rules, webhook wiring.

Memory

What it adds

Conversation Memory keyed to the user (de-referenced by phone number), surfaced to the admin before, during, and after conversations. You text yourself and watch memories form in real time.

LAYER 03

Agent tools

What it adds

The full agent tool set — rebook, seat change, upgrades — as admin-gated actions on another user's behalf. The "call in and get something done" experience, with a human in the agent seat. These are the exact tools the AI inherits later.

In the Console

No new Console work — this layer lives entirely in the app.

Intelligence

Conversation Intelligence operators — summaries, follow-up texts, upgrade detection — driving live triggers on the admin panel. This is the "value without AI agents" plateau: real intelligence, human still in the seat.

In the Console

Operator authoring, associations to Memory and Orchestrator, webhooks.
